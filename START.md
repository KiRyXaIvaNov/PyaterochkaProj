# Быстрый запуск

## 1. Backend

Открой терминал в папке `backend`:

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

Установить зависимости:
```bash
pip install -r requirements.txt
```

Запустить:
```bash
uvicorn main:app --reload --port 8000
```

Проверка: открыть `http://localhost:8000/`.

## 2. Frontend

Во втором терминале открыть `frontend`:

```bash
npm install
npm run dev
```

Открыть адрес, который покажет Vite (обычно `http://localhost:5173`).

## 3. Вход

Пользователь: любая корректная почта, например `student@tpu.ru`.

Администратор: `admin@tpu.ru`.

Пароль в MVP не проверяется — это демонстрационная авторизация.

## 4. Проверка сценария

1. Войти как `student@tpu.ru`.
2. Написать: `Не работает Wi-Fi`.
3. Нажать `Нужен специалист`.
4. Выйти.
5. Войти как `admin@tpu.ru`.
6. Открыть обращение и ответить пользователю.
7. Вернуться в пользовательский аккаунт — ответ специалиста появится автоматически примерно через 3 секунды.
